# The messaging apps' marks

The real mark of each app a draft can go through (the owner's ask of 20 Nov 2026: proper, standard icons, never a generic bubble). Vendored with their path data as published (only reformatted), not yet processed: they become the phone's custom symbols in one pass, to one standard, later.

- Source: [simple-icons](https://simpleicons.org) on npm, CC0 for the path data; each mark stays its company's trademark, used only to name where a message goes.
- Versions: `whatsapp`, `telegram`, `line`, `gmail`, `linkedin` from 9.21.0; `imessage`, `instagram` from 13.21.0; `messenger` from 15.0.0. These are the paths the design canvas draws (`net_marks.py`).
- One file per app, named as Life names the network (`sources/networks.ts`); `gmail` is mail sent through Gmail, `imessage` Apple's Messages.
