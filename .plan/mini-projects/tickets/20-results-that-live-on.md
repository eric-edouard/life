# Results that live on

## Question

Some projects leave a result that keeps running after it is built, with data of its own (the owner's example: a party invite system, where guests open a page, answer, and the user follows who is coming). Where it is hosted and stores its data (Life's artifact system), when such a project is "done", and how its agent wakes on its events (an answer, a link opened) to tell the user ("12 coming, 2 maybe, 3 declined, 4 silent").

## Answer

Decided with the owner on 28 Nov 2026. A result that keeps running is hosted, with its data, on Life's artifact
system. The project stays active until its end date (the party): its agent wakes on the result's events (an answer, a
link opened) and updates the project's one quiet line; after the end date it ends `done` with its report.
