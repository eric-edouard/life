# The agent's workspace

## Question

Where a project's agent works (its folder, its scripts, git, its notes), what it keeps when the project ends, and how its tools are tried on a sample before the real data.

## Answer

Decided with the owner on 28 Nov 2026. The agent's work (its scripts, `PLAN.md`, git, tools) lives hidden, in Life's
agents repo under the project; the result goes where the user would look: a visible folder for a file (a PDF, a CV),
or a Life page for something to open (a site, a report). Kept after the end (Progress and the end); tools are tried on
a sample before the real data (the playbook).
