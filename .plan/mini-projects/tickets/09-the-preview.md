# The preview

## Question

For each kind of one-off project, what cheap preview of the result is shown before real work (a sample done for real, a clickable fake, an outline), how fast, how feedback rounds work, and how its approval becomes the plan's approval. Uses Life's artifact system.

## Answer

Decided with the owner on 28 Nov 2026.

- **The preview is the cheapest thing that shows the result**, never the user's real things: a clickable fake (a site,
  an RSVP page), a draft (a trip plan, a CV, a recipe book), or a simulated end state (a move of notes, a cleanup, an
  invoice filing). Built in the playbook's stack, so it grows into the result.
- **Rounds on one page:** each round of feedback is a new version of the same artifact; one tap, "Build it", approves.
