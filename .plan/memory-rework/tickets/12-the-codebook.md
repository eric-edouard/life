# The codebook

## Question

Which families of codes, each its own focused read, and which codes in each: merge the trait and dyad shortlists (research 01, 02, 14) into one codebook, each code defined with what it is and is not, the opportunities it needs (so avoidance isn't absence), and who it is about.

## Decided by the designer (10 Nov; spec section 5)

- Four focused reads of an exchange beside today's two: connection; conflict and steering; giving and asking;
  mentions and self-reports. Each code names who did it and to whom, with the quote, and what it answered, so rates
  are per chance to act.
- The wording of each code is frozen on the pilot. Whether the day's read may route exchanges to reads is a pilot
  test.
