# The helper for each job

Reference: the existing helper for each need in the server. Before adding a helper, find the one that exists here (search this page for the need). One way to do each thing: `.claude/rules/one-way.md`.

| Need | Use |

| Which matter some refs name (an agent's anchors, a direction's pinned steps, a matter or step id the owner gives) | `matterOfSteps`, or `matterFinderOf` for many lookups (`memory/matter-read.ts`): the matter holding the most of the refs (as its id or its steps; a unit can be a step of several), on a tie the matter it was given (`prefer`: a pin's `matter`, an assignment's `matter_id`), then the one with the fewest steps |
