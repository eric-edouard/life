What each chat takes

A draft into each app, by Life's ChatTakes (reply, mentions, reaction, file) and a bridge's caption on a file. A bridge says it per room: these are what each app's bridge usually says. iMessage sends a file, then its words as a second message. A voice note is an audio file.
